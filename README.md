# Marci Metzger Homes — React + Vite + Tailwind CSS

Converted from the supplied single-file React/Tailwind HTML page.

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Structure

- `src/App.jsx` — page components and interactions
- `src/index.css` — Tailwind CSS v4 theme + custom animation/scroll styles
- `src/main.jsx` — React entry point
- `vite.config.js` — Vite + React + Tailwind integration

The image URLs from the original page are intentionally preserved.
